# MBM | مركز المعرفة

موقع تعليمي عام فيه روابط الأدوات، مع التعليمات وملخصات التجارب والنصائح لكل أداة.

## الصفحات

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية وكروت الأدوات |
| `tool.html` | صفحة الأداة |
| `admin.html` | لوحة التحكم |

## قاعدة البيانات

الجداول:

```
hub_tools
hub_entries
hub_admins
```

القراءة متاحة للجميع، والتعديل للبريد المسجل في جدول المديرين فقط.

لإضافة مدير جديد:

```sql
insert into public.hub_admins(email) values ('name@example.com');
```

## النشر

النشر يتم تلقائياً عند الدمج في الفرع الرئيسي عن طريق الملف:

```
.github/workflows/pages.yml
```
